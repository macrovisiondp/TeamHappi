## Rollback

- **Atomic:** the migration runs as one transaction.
- **While no rota has been created,** reversing it uses the statements in its header. That would be a separately approved run.
- **Code rollback without a database rollback is safe:** older code ignores the tables. The permissions would simply have no page.
