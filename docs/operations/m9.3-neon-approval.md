  - **Your "Senior Chef" link is already shared,** so it can receive real applications as soon as this is deployed.

  - **If you'd rather wait,** pause the vacancy or remove its link first.
- **What doesn't change:** nothing else.

## Rollback

- **Atomic:** the migration runs as one transaction.
- **Reversing it** uses the statements in its header. That would be a separately approved run.
- **Code rollback without a database rollback is safe:**
  - older code calls `app.public_vacancy` and ignores its extra column;
  - it never calls the new functions.
