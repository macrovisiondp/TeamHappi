# Procedure: provisioning the first platform administrator

**Status:** requires separate product-owner approval of this exact procedure. Not executed.

**Why a manual step:**
- Until one administrator exists, nobody can add staff through the app.
- Platform access is never granted automatically from an email address.
- This one-off step is run deliberately by the product owner, and it is audited.

## Preconditions

1. The M5.1 migration is applied and verified (`m5.1-neon-approval.md`).
2. The administrator's TeamHappi account **already exists and is verified**: `<platform-admin-email>`.
3. `platform_staff` is empty. The script stops otherwise.

## Steps (product owner, in the Neon SQL Editor, database `teamhappi`)

Replace `<platform-admin-email>` with the approved address, then run:

```sql
BEGIN;

DO $$
DECLARE v_user uuid;
BEGIN
  IF EXISTS (SELECT 1 FROM platform_staff) THEN
    RAISE EXCEPTION 'Platform staff already exist: add further staff in Platform Admin.';
  END IF;
  SELECT id INTO v_user FROM "user"
   WHERE email = lower('<platform-admin-email>') AND email_verified;
  IF v_user IS NULL THEN
    RAISE EXCEPTION 'No verified account for that email.';
  END IF;

  INSERT INTO platform_staff (user_id, grants)
  VALUES (v_user, ARRAY['staff.manage','tenant.view','tenant.suspend',
                        'tenant.create','integrations.manage','audit.view']);

  INSERT INTO platform_audit_event (actor_user_id, action, target_user_id, target_type, target_id, detail)
  VALUES (NULL, 'staff.granted', v_user, 'user', v_user::text,
          '{"via":"bootstrap-procedure","grants":["staff.manage","tenant.view","tenant.suspend","tenant.create","integrations.manage","audit.view"]}');
END $$;

COMMIT;

-- Check: one row, status active, six grants.
SELECT u.email, s.status, array_length(s.grants, 1) AS grants
FROM platform_staff s JOIN "user" u ON u.id = s.user_id;
```

## Afterwards

1. Sign in as the administrator and open `/platform`. You're sent to **Set up multi-factor authentication**.
2. Scan the QR code with an authenticator app, enter the code, and **save the 10 recovery codes** somewhere safe.
3. You land on Platform Admin. The audit log shows `Added platform staff` (bootstrap) and `Turned on MFA`.
4. Add further staff only through **Platform Admin → Staff**.
