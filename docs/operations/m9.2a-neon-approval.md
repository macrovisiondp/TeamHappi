## Effect on Joemis Kitchen and other organisations

- **What changes:** a "Share this vacancy" card appears on each vacancy for people who can manage it.
- **What doesn't:** nothing becomes public until someone creates a link, and links show only the fields described in `docs/architecture/m9.2a-vacancy-sharing.md`.

## Rollback

- **Atomic:** the migration runs as one transaction.
- **Reversing it** uses the statements in its header comment:
  - drop the function;
  - drop the constraints, the index and the five columns.

  This would remove any share links (people opening them would see "Page not found") and the counts. It would be a separately approved run.
- **Code rollback without a database rollback is safe:** older code ignores the new columns and doesn't call the function.
