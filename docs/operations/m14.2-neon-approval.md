## Needed before real use

`PERSONAL_DATA_KEY` set in Vercel (Production and Preview separately). Generate it with:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

Until it's set, NI and bank fields are switched off.

## Rollback

The SQL is at the top of the migration file. It's safe only while the table is empty, and it would be a separately approved run.
