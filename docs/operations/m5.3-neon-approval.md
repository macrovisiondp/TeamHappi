## What this does NOT approve

Each of these needs its own, separate approval:

- **Accepting ADR-0011 stage 1** (keys in Vercel environment variables, metadata only in the app). The code follows it; the ADR is still marked proposed.
- **Any live provider** (Resend, SES, S3, Cloudinary, Stripe, Paystack, Flutterwave, any AI provider). Each one needs its keys added in Vercel, its name added to `APPROVED_LIVE_PROVIDERS`, and a live adapter (code that makes network calls), which doesn't exist yet.
- **Paid API use**, and any processing of real client data by a provider.
