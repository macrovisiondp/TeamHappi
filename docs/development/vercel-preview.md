# Vercel preview: plan and eligibility

Status: **prepared, not deployed.** Nothing has been created in Vercel.

## Plan eligibility (owner decision needed)

Vercel's Hobby plan is for **personal, non-commercial use**.

TeamHappi is a commercial product of Macrovision Digital Solutions. Even a private preview built to develop it is likely to count as commercial use under Vercel's fair-use terms. I can't confirm eligibility on your behalf.

| Option | Cost | Notes |
|---|---|---|
| 1. Stay local, no hosted preview | Free | What we do today. Fully compliant. |
| 2. Ask Vercel to confirm a protected, synthetic-only development preview is allowed on Hobby | Free if allowed | Get the answer in writing before deploying. |
| 3. Vercel Pro for the project | About $20 per member per month | Allows commercial use; adds better deployment protection options. Paid, so it needs your approval. |
| 4. A host whose free tier allows commercial use (for example Cloudflare or Netlify free tiers) | Free | Needs an ADR, because it changes ADR-0003. Next.js 16 features need checking. |

**Recommendation: option 1 until option 2 or 3 is decided.** The configuration below works for any of the Vercel options.

## Configuration

- **Framework:** Next.js, detected automatically.
  - Build: `npm run build`. The Prisma client is generated by the `postinstall` script during Vercel's `npm install`, so no extra build step is needed.
  - Node: 22 (from `.nvmrc`).
- **`vercel.json`:**
  - functions run in **`lhr1` (London)**, next to Neon `aws-eu-west-2`;
  - `git.deploymentEnabled.main` is `false`, so nothing deploys to production automatically.
- **Preview access protection:** turn on **Vercel Authentication** (Deployment Protection, "Standard Protection"), so only signed-in members of the Vercel team can open previews. Never share preview URLs publicly.
- **Authentication URLs:**
  - `APP_URL` must equal the deployment URL. Better Auth uses it for cookies and verification links.
  - For previews, set `APP_URL` to the stable branch alias (for example `https://teamhappi-git-<branch>-<team>.vercel.app`).
  - Cookies are `__Secure-` because previews use https.

## Rollback

- **App:** Vercel "Instant Rollback" or "Promote" to the previous deployment. Previews are immutable, so you can always go back to an older URL.
- **Database:** migrations are expand/contract, so the previous build stays compatible. If a schema change goes wrong, restore from the recovery branch created just before it (each one needs approval).
- **Secrets:** roll back to the superseded credential version (ADR-0011).

## Before the first preview deploy (approvals)

1. Plan eligibility decision (above).
2. M3.1 auth role and migration on Neon. Without them, previews can't sign anyone in.
3. Approval to create the Vercel project and connect the GitHub repository.
4. Approval for the specific environment variables and which Neon branch previews use.
